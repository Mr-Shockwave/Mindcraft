# Four-Minute Demo Script

**Persona:** university student, three minutes before presenting.  
**Input:** `I feel anxious about presenting my project.`  
**Action:** `Open my notes and say the first sentence.`

## Live product (Person A leads · ~0:00–2:15)

1. Name the user and what breaks today: no time for a session; generic advice adds load.
2. Paste the default feeling → **Place it on my island** (manifest).
3. Show three tray forms → drag one onto the island.
4. Choose a tool (e.g. breathe) → **Try this interaction** → symbol transforms.
5. Plant the intention → stage becomes `integrated`.
6. Say: *“The feeling was not destroyed. The island made room for it while they took a valued step.”*
7. Optional: **Reset demo** once for a clean second pass.

## Jac evidence (Person B leads · ~2:15–3:20)

Follow `docs/JAC_EVIDENCE.md`:

1. Nodes/edges in `main.jac`
2. `by llm()` + validation
3. Walkers as the workflow
4. `components/App.cl.jac` spawn calls
5. One test name from `tests/core_tests.jac`

## Close (Person A · ~3:20–4:00)

- Social impact: low-barrier emotional externalization for high-pressure students.
- Boundary: not therapy; crisis redirects to human support.
- Close line: *“Mind Island helps a student take the next valued step without first defeating how they feel.”*

Deterministic fallback still completes the path. Do not apologize mid-demo — continue.
